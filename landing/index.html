Возможности

Всё необходимое для создания умного ИИ-ассистента

Cloud + Local LLM

Гибридная архитектура: облачные провайдеры (Gemini, Claude, GPT, DeepSeek, Kimi, OpenRouter) или локальный vLLM (Qwen, Llama)

Голосовое клонирование

XTTS v2 для клонирования голоса, Piper для быстрой генерации, Vosk STT для распознавания речи

Telegram и WhatsApp боты

Мульти-инстансные боты с воронками продаж, FAQ, оплатой. Независимая настройка LLM и TTS для каждого бота

Чат-виджеты для сайтов

Встраиваемые виджеты с одной строкой кода. Сохранение истории, streaming, кастомизация стилей

FAQ + База знаний (Wiki RAG)

Семантический поиск с embeddings + BM25 fallback. Загрузка .md/.txt документов, автоматический reindex

Vue 3 Админ-панель

20 вкладок, PWA, i18n (ru/en), RBAC (4 роли), dark/light тема. Управление всем из браузера

Fine-tuning (LoRA)

Тонкая настройка LLM на ваших данных через LoRA адаптеры. Управление моделями и адаптерами из админки

amoCRM + Воронки продаж

OAuth2 интеграция с amoCRM, квиз-воронки в ботах, сегментация, YooMoney оплата, рассылки

GSM-телефония + OpenAI API

Телефония через SIM7600E-H модем. OpenAI-совместимый API для подключения к любому клиенту

Два режима работы

Выберите подходящий вариант в зависимости от вашего оборудования

Cloud Mode

Без GPU

Работает на любом VPS. Облачные LLM и TTS.

  • Cloud LLM: Gemini, Claude, GPT, DeepSeek, Kimi
  • OpenRouter (бесплатные модели)
  • Telegram и WhatsApp боты
  • Чат-виджеты для сайтов
  • FAQ и база знаний (Wiki RAG)
  • Vue 3 админ-панель (PWA)
  • amoCRM интеграция
  • Воронки продаж + YooMoney

Full Mode

GPU + Cloud

Все возможности: локальные LLM, голосовое клонирование, телефония.

  • Всё из Cloud Mode +
  • Локальный vLLM (Qwen, Llama, DeepSeek)
  • LoRA fine-tuning
  • Голосовое клонирование XTTS v2
  • Vosk STT (распознавание речи)
  • GSM-телефония (SIM7600E-H)
  • Мониторинг системы (GPU, RAM, CPU)
  • Claude Code Bridge (CLI → OpenAI)

Установка

Клонируйте репозиторий и запустите через Docker

git clone https://github.com/ShaerWare/AI_Secretary_System.git
cp .env.docker.example .env
docker compose up -d

Настройка

Откройте админ-панель и настройте LLM провайдера, ботов и виджеты

Откройте http://localhost:8002/admin
Логин: admin / admin

Запуск

Разверните ботов, подключите виджеты к сайту, настройте amoCRM

<script src="https://your-server.com/widget.js?instance=main" defer></script>
