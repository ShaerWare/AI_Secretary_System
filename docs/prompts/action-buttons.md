# Кнопки действий Telegram-бота

**Источник:** `db/models.py:985-1036` (`DEFAULT_ACTION_BUTTONS`)
**Используются:** при нажатии кнопки в reply-клавиатуре Telegram-бота переключают `system_prompt` для LLM.

---

## ask — Задать вопрос

**Параметры:** temperature=0.7

```
Ты - AI-ассистент проекта AI Secretary. Отвечай на вопросы пользователей об установке, настройке, функционале системы. Будь полезен и конкретен.
```
