# Request discount code

## Please enter your details below to request a discount code

In order to provide a IFRS discount code, the Institute will confirm membership to the IFRS. The Institute has entered into a controller to controller agreement with the IFRS for the sharing of personal data of members in order to facilitate applying this discount code. Under the agreement, only strictly necessary personal data is shared by the Institute with the IFRS. The personal data shared is limited to confirmation of membership of individuals with the Institute (name of members). The IFRS will process this data for the purpose of verifying requests from members and applying the discount code as agreed between the parties. Further information on the privacy policy of IFRS can be found here https://www.ifrs.org/legal/privacy/.
