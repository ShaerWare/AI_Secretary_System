Questions

Frequently asked questions

How is this different from a regular chatbot?

Regular bots run rigid scenario trees. Sekretar24 is real AI powered by Claude (Anthropic): it understands free text, remembers conversation context and answers from your knowledge base, not from a script.

Which AI does Sekretar24 use?

By default — Claude by Anthropic, the smartest and most steerable model on the market. On request we plug in any other: OpenAI GPT-4, Google Gemini, Moonshot Kimi, DeepSeek, OpenRouter (dozens of models in one API) or local Qwen/Llama/DeepSeek via vLLM on your own server.

What happens to the AI after the trial?

The trial runs on Claude. After — two options: stay on Claude with Business+, or switch for free to OpenRouter's powerful models (DeepSeek R1, Llama 3.3 70B, Qwen 2.5 72B). The chain is configured from strongest to weakest: if the top model hits a limit, the assistant automatically takes the next one. For most tasks free models are more than enough.

Can I install it myself?

Yes. Code is open on GitHub under MIT, with detailed documentation. You need Docker and root SSH access on any Linux server. If you'd rather not bother — we install turnkey for 5,000 ₽.

How much does the AI cost?

For most business tasks OpenRouter's free models (DeepSeek, Llama, Qwen) are enough. Paying for top models (Claude, GPT-4) makes sense for complex reasoning and maximum expertise. On cloud plans the API is included; on self-hosted you plug in your own key or use the free models.

What's included in the 5,000 ₽ turnkey installation?

We deploy Sekretar24 on your server (Docker + root SSH required), configure the knowledge base (RAG), connect Telegram/WhatsApp/widget/telephony, and tune the assistant for your niche. Payment via YooMoney, Ozon Pay or Alfa-Bank.

Is my data safe?

Yes. Cloud models or your own server — your choice. Self-hosted means customer data stays inside your perimeter, and the open-source code can be audited.

Do I need my own server?

Not for cloud plans — everything runs at our end. For self-hosted from GitHub you need any Linux server with Docker (from 2 GB RAM for cloud mode, from 12 GB + GPU for local AI).

Which channels does the assistant work on?

Telegram, WhatsApp, web chat widget, telephony and the Android app. One assistant — every channel at once.

Can I connect telephony?

Yes, starting with the Business plan. The assistant takes and makes calls, recognizes speech and answers in voice.
