Вопросы

Частые вопросы

Чем это отличается от обычного чат-бота?

Обычный бот работает по жёсткому сценарию-дереву. Секретарь24 — это настоящий ИИ на базе Claude от Anthropic: понимает свободную речь, помнит контекст диалога и отвечает по вашей базе знаний, а не по скрипту.

Какой ИИ использует Секретарь24?

По умолчанию — Claude от Anthropic, самая умная и обучаемая модель на рынке. По запросу подключаем любой другой: OpenAI GPT-4, Google Gemini, Moonshot Kimi, DeepSeek, OpenRouter (десятки моделей в одном API) или локальные модели Qwen/Llama/DeepSeek через vLLM на вашем сервере.

Что будет с ИИ после триала?

На триале работает Claude. После — два варианта: продолжить на Claude по подписке Бизнес+, или бесплатно переключиться на мощные модели OpenRouter (DeepSeek R1, Llama 3.3 70B, Qwen 2.5 72B). Цепочка настроена от мощных к слабым: если первая модель упёрлась в лимит — ассистент автоматически берёт следующую. Для большинства задач бесплатных моделей более чем достаточно.

Можно ли установить самому?

Да. Код открыт на GitHub под лицензией MIT, есть подробная документация. Нужны только Docker и root-доступ по SSH к любому Linux-серверу. Не хочется возиться — установим под ключ за 5 000 ₽.

Сколько стоит ИИ?

Для большинства бизнес-задач хватает бесплатных моделей OpenRouter (DeepSeek, Llama, Qwen). Платить за топ-модели (Claude, GPT-4) имеет смысл там, где нужны сложные рассуждения и максимальная экспертиза. На облачных тарифах API уже включён, на самохостинге — подключаете свой ключ или бесплатные модели.

Что входит в установку под ключ за 5 000 ₽?

Развернём Секретарь24 на вашем сервере (нужны Docker и root SSH), настроим базу знаний (RAG), подключим Telegram/WhatsApp/виджет/телефонию, обучим ассистента под вашу нишу. Оплата картой — YooMoney, Ozon Pay или Альфа-Банк.

Безопасны ли мои данные?

Да. Облачные модели или собственный сервер — выбор за вами. На самохостинге данные клиентов не покидают периметр, а open-source код можно проверить.

Нужен ли свой сервер?

На облачных тарифах — нет, всё работает у нас. Для самостоятельной установки с GitHub нужен любой Linux-сервер с Docker (от 2 ГБ ОЗУ для cloud-режима, от 12 ГБ + GPU для локального ИИ).

С какими каналами работает ассистент?

Telegram, WhatsApp, чат-виджет на сайте, телефония и Android-приложение. Один ассистент — все каналы одновременно.

Можно ли подключить телефонию?

Да, начиная с тарифа Бизнес. Ассистент принимает и совершает звонки, распознаёт речь и отвечает голосом.
