# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep criticism about the code and not the person, and no harassment of any kind. English and Russian are both welcome in issues, PRs and Discussions.

Report unacceptable behaviour privately to the maintainers through [GitHub Security Advisories](https://github.com/ShaerWare/AI_Secretary_System/security/advisories/new) or the [project assistant in Telegram](https://t.me/ai_sekretar24bot). Reports are handled confidentially.
